**Headline**  
AI Engineer | LLM Gateway & Schema-Grounded Text-to-SQL Systems

**Summary**  
Software engineer building production AI systems. Built a thin multi-provider LLM gateway and an internal Q&A flow that routes general questions vs. business-data questions, then answers from live database results via Text-to-SQL with table allowlisting and schema grounding. Currently adding document retrieval as a separate path.

**Bullets**
- Built a thin LLM gateway with a unified response contract across providers; callers set provider, model, max tokens, and temperature per request.
- Implemented default cost-tier fallback when no model is specified, plus model availability checks and explicit errors for outage, quota, and unknown models. API keys never leave the gateway.
- Shipped an organization chatbot that classifies intent, then retrieves business data through Text-to-SQL instead of unconstrained model memory.
- Grounded SQL generation in an allowlist of tables/views and a data dictionary; inspect queries before execution and answer only from returned rows.
- Logged executed queries and results in the production usage path to make answers auditable.
- Integrated web search as a tool for questions that need external information, while keeping orchestration in the application layer rather than inside the gateway.
